# Issue tracker: GitHub

Issues and specs live in GitHub Issues for Eloyye/pb-stats.
Use the gh CLI from this repo for tracker operations.

- Publishing to the issue tracker means creating a GitHub issue.
- Fetching a ticket means reading its body, labels, and comments.
- Use --body-file for multiline issue bodies and comments.
- Follow the user's authorization before posting comments or other messages.

## Pull requests as a triage surface

PRs as a request surface: no.
